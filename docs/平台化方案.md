# CanDo 平台化方案（草案，2026-09-29）

目标：把 CanDo 从“课题组内部工具”变成打破学术壁垒、面向新一代年轻人的科研公平交流平台。

## 年轻人做科研的四道门槛
| 门槛 | 表现 | CanDo 现状 |
|---|---|---|
| 知识 | 论文看不懂，不知道从哪开始 | 已有：AI 速读、概念讲解、写论文向导 |
| 规范 | 格式、方法、引用、诚信没人教 | 已有：格式检查、引用核验、逐句标依据 |
| 资源 | 没导师、没数据、没设备 | 缺 |
| 圈子 | 做出来没人看；评价看学校和头衔 | 缺（最难、最重要） |

## 核心设计
1. **把发表单位拆小**：问题、想法、数据、失败的实验、复现、代码、评审都能单独发布、互相串联、各自署名（参考英国 Octopus 平台的 8 种单元）。
2. **公平机制**
   - 先看内容再看人：评审默认匿名，评完再显示作者和学校。
   - 看证据：把“每句话有依据、引用真实、附数据和代码、可复现”做成公开的“证据分”。
   - 每份贡献都记名（谁提问、谁做实验、谁写代码）。
   - 推荐不按粉丝数：新人流量池 + 按研究方向匹配。
   - AI 使用透明：标注 AI 辅助程度，坚持“AI 帮你做，不替你做”。
3. **把人和资源连起来**：老师/课题组发布“开放问题”，外校学生认领并获得署名；找队友、找数据、导师答疑时间；成长路径（读懂 → 复现 → 改进 → 原创）形成作品集。
4. **本地版 + 公开平台**：本地工作台继续“数据留在本机”，想公开的内容一键发布到公开平台。

## 难点
- 合规：公开网站需要备案、实名、内容审核；面向公众的生成式 AI 服务需按规定备案或登记；有未成年用户须满足《未成年人网络保护条例》。需找专业人士确认。
- 学术诚信：杜绝代写和论文买卖。
- 冷启动：从大创、挑战杯、数学建模圈子开始；经作者同意公开往届经验库作为种子内容。
- 成本：服务器、审核、AI 调用。学生免费，靠学校/教改项目/公益基金，机构付费。

## 三步走
1. **校内联盟版**：几个课题组、几个学校互通，共享开放问题和经验库，跑通“开放问题 + 署名”。
2. **公开测试版**：小单元发布、匿名评审、证据分；先只面向大学生。
3. **全面开放**：完成未成年人保护措施后开放给中学生，接入机构，对接预印本和论文编号（DOI）。

## 已决定（2026-09-29）
- 技术形态：第一步在现有 Go 程序上加“联盟同步”（先文件交换，再加中转站），数据格式按以后的公开平台设计。
- 第一步：先写产品方案（`docs/论坛模式.md`），再做可点击原型，然后开发校内联盟版。
