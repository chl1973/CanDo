CanDo

手机 App · 连接老师电脑使用

苹果手机（iPhone / iPad）

苹果手机用“添加到主屏幕”安装：桌面上会出现“CanDo”图标，打开后全屏显示，用起来和 App 一样，不需要 App Store。

  1. 用 Safari 打开（在微信里请点右上角“…” → “在默认浏览器中打开”）。
  2. 点下面的按钮打开工作台首页，先登录。
  3. 点屏幕底部（iPad 在右上角）的“分享”按钮 ，往下找到“添加到主屏幕”，点右上角“添加”。
  4. 以后从桌面的“CanDo”图标打开即可，登录状态会保留。

老师如果有 Mac 电脑和苹果开发者账号，也可以用源码包里的 ios 文件夹编译原生 App（说明见 ios/README.md）。

安卓手机

  1. 点上面的按钮下载，下载完成后点“打开”。
  2. 如果提示“禁止安装未知应用”，按提示到设置里允许当前浏览器安装应用，再返回点“安装”。
  3. 如果提示“未经检测 / 风险应用”，这是因为 App 没有上架应用商店，点“继续安装”即可。
  4. 打开“CanDo”，输入下面的地址点“连接”，然后登录：

（地址）

建议在微信里长按二维码识别后，点右上角“…” → “在浏览器中打开”再下载；微信内置浏览器可能无法直接下载安装包。

手机和老师电脑需要连同一个 Wi-Fi；所有资料都保存在老师电脑上。
