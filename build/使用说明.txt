CanDo 可为 v1.15.0 使用说明
================================

一、这是什么
  把课题组的科研和竞赛做成规范的流水线：
  · 论文库（1.7 整合）：原来的“资料”“文献检索”“Zotero 导入”合成一个“论文库”，分三块：库中论文（上传、OCR、AI 速读）、
    检索添加（在线检索、Zotero、题录导入）、深度调研。检索或 Zotero 导入的是扫描版 PDF 时，会提示直接 OCR。
  · 全文组装（1.15 新增）：写论文 → 全文组装。把“AI 起草”里写好、确认过的各节拼成一篇完整的论文，导出 Word、LaTeX，
    本机装了 LaTeX 时还能直接编译成 PDF。拼装不用 AI：正文逐字来自各节草稿，题目和关键词由你自己填，
    参考文献按全文第一次引用的顺序统一编号。导出前由程序检查：必需的章节都有草稿吗、每一节都做过“导出前确认”吗、
    是不是按同一版论文契约写的、契约里每条核心主张的依据有没有写进论文、承认的局限有没有交代、
    承认因果没证实时有没有用“导致、提高”这类说法、还剩几处【需补充】，再用“格式检查”同一套规则查一遍。
    标红的问题不解决不能导出；提醒要逐项勾选确认。确认之后换了草稿、改了题目或某一节重新起草，要重新确认。
    附录、成果清单、数据声明这些 AI 不起草的部分，导出后要自己补上；图表和公式也要自己插入。
  · 外部工具服务（1.15 新增，给会编程的合作者用）：AI 助手 → 本机智能体 → 文件夹与权限 → 外部工具服务。
    合作者可以用 Python 等语言写一个在本机运行的小程序，把画图、把图插进 Word / LaTeX、解析模板等能力做成“工具”，
    填上地址（如 http://127.0.0.1:8765）接入后，智能体就能调用。只能接这台电脑上的服务；
    文件由 CanDo 在授权文件夹里读出后交给工具，工具生成的文件交回 CanDo，由你确认后才保存，保存前备份、可撤销；
    每个外部工具第一次调用都会先问你，可以设为“始终允许”，也可以随时改回。写法见源码里的 docs/外部工具接口.md
    和示例 tools/extool/example_server.py。普通使用不需要这一项。
  · 本机智能体会用 Office 了（1.14 新增，参考了同学的脚本）：AI 助手 → 本机智能体，在你授权的文件夹里：
    读 Word（.docx，按段落编号显示，标出标题、图片、表格）、Excel（.xlsx，按行列显示）、PPT（.pptx，按页显示）；
    改 Word：替换、在某段后插入、删除段落，保留原有的字体、排版、图片、表格和公式，含图片或公式的段落不会被改；
    新建 Word：把写好的内容排成宋体小四、1.5 倍行距、黑体标题的文档（支持标题、列表、三线表、加粗、居中、分页）；
    分析 Word 模板的格式（页边距、各级标题和正文用的字体字号、行距）；把 Word 里的图片导出成文件。
    所有修改和新建都要你在右侧确认后才写入，写入前自动备份，可以一键撤销；不会覆盖已有文件。
    旧格式 .doc / .xls / .ppt 请先用 Office“另存为”新格式。
  · 联网搜索（1.14 新增）：设置 → 联网搜索，填一个搜索服务的密钥（国内推荐博查，国外可用 Tavily），
    本机智能体就能上网查资料（竞赛通知、软件报错、模板写法），回答时附来源链接。学术文献仍建议用“论文库 → 检索添加”。
  · 便携 LaTeX（1.14 新增）：没装 TeX Live 也能编译 LaTeX 论文。设置 → 本机智能体 → LaTeX 编译里点
    “一键下载 Tectonic”（约 30 MB），第一次编译会自动下载需要的宏包（要联网）。已装 TeX Live / MiKTeX 的仍优先用它们。
  · 更稳的智能体（1.14）：有些模型（如 DeepSeek）偶尔会输出自己的“工具调用标记”而不是规定格式，现在能自动识别并照常执行；
    图片可以直接给路径让智能体识别（公式、表格、截图）。
  · 对照契约检查（1.14 新增）：按论文契约写的草稿，起草后点“对照契约检查”，逐句找出写偏的地方：
    超出契约的新主张、与契约矛盾、漏答这一节的问题、把待解决问题写成已解决、没写承认的局限、把相关写成因果。
    其中“契约承认因果未证实，正文却用了‘导致、提高’等因果说法”和“讨论/结论没交代局限”由程序直接判断；
    AI 指出的问题必须对应到具体句子，对不上的不采信。
  · 导出前确认（1.14 新增）：复制正文或下载 Word 之前，要逐项勾选：会核对事实和引用、会补全【需补充】、
    会处理标黄和对照契约发现的问题、会用自己的话修改并声明使用了 AI。按契约写的草稿必须先做对照契约检查。
    重新起草或重新检查后需要重新确认。
  · 请老师审阅论文契约（1.14 新增）：契约确认后点“请老师审阅”，选一位老师。老师首页“待我处理”会出现这份契约，
    打开后只能查看（不能改学生的契约），可以“通过”“退回修改”或写评论；退回后学生首页会提示。
    学生解锁修改契约时，审阅请求自动撤回，改完重新确认后再请老师看。
  · 论文契约（1.13 新增）：写论文 → 论文契约。动笔之前先把论文“要证明什么”写清楚：
    ① 研究问题（一句话问题、变量及测量方法、研究方法、研究边界）；② 2–3 个核心主张，每个写明创新点、依据（N/F 编号）
    和“什么情况下不成立”；③ 章节地图：每一节回答什么问题、用什么证据、得出什么结论、和前后节的关系。
    生成后会强制跑一轮“审稿人攻击”：相关≠因果、反过来成立吗、混杂变量、样本、测量、推广性等。
    每条质疑可以：回应（拿出数据、实验设计或 N/F 编号）、写进局限、保留为待解决。
    反谄媚规则：只有回应直接回答了质疑的核心、并且给出了可核对的证据，审稿人才会让步；坚持、表态、
    “大家都这么认为”、“以后会补充”都不算。这条规则由程序强制执行，不靠 AI 自觉。
    全部处理完、本人确认后契约锁定（版本 v1、v2……）。之后在“AI 起草”里选“按论文契约写”，
    骨架和成文都不会超出契约，契约里承认的局限会如实写出。契约可以导出为文档给老师看。
  · 新名字与新图标（1.12）：“科研竞赛工作台”改名为“CanDo 可为”——Everyone can do research，人人都能做科研。
    图标是一个圆点（每个人）加一个勾（做成了）。主色换成深群青，页面背景为暖白纸色。
    从旧版升级：直接运行新安装包即可，数据、账号、论文都不变（数据位置不变）；旧的“科研竞赛工作台”桌面图标和开始菜单会自动换成新的。
    程序文件改名为 CanDo.exe。
  · 新界面（1.11）：整体视觉精修（统一的线条图标、卡片层次、登录页）；支持深色模式——右上角的半圆图标在
    “跟随系统 / 浅色 / 深色”之间切换，也可以在“设置 → 外观”里选，只对当前这台设备生效。
  · 首页总览（1.11 新增）：进行中的项目、我的论文（含全组共享数）、AI 草稿、待我审核（学生显示待办数），
    常用入口（上传论文、AI 起草、格式检查、图片转 LaTeX、深度调研），“待我处理”（待审核、被退回、7 天内到期或已逾期的阶段，
    点一下直接打开该阶段），以及最近的论文和最近的草稿（点草稿直接打开）。
  · 论文库更好用（1.11）：把文件拖到上传框，或点一下选择文件（可以一次选多个）就会自动上传；列表可以按标题、作者、文件名搜索，
    按“可用 / 需要 OCR / 已共享”筛选；“提取的文字”“共享到全组”“删除”收进每行右侧的“⋯”菜单。
  · 手机底部导航（1.11）：只保留 首页 / 项目 / 论文库 / 写论文 / 更多 五个，AI 助手、经验库、格式检查、深度调研、后台、设置和外观切换在“更多”里。
  · 后台运行（1.10 新增）：AI 起草、生成论证骨架、列提纲、格式检查、问答、对比、AI 速读、概念讲解都在工作台后台运行，
    关掉或离开页面不会中断，可以同时发起多个（每人最多 3 个同时运行，其余自动排队）。右上角“后台任务”显示进度，完成时提示，
    点“查看结果”跳回对应页面。
  · 全组共享（1.9 新增）：个人论文库里的论文可以逐篇“共享到全组”，组内所有成员在“论文库 → 全组共享”里都能看到（只读），
    可以速读、提问、在 AI 起草中引用；只有上传者可以修改、删除或取消共享。
  · AI 起草（1.9 新增）：写论文 → AI 起草。写下你自己的想法和结果，选几篇论文库里的论文，AI 按论文写作规范先搭“论证骨架”，
    你确认或修改后再起草成文；每句话都标出依据（你的材料或论文原文），没有依据的句子标黄，缺的内容留【需补充】，可导出 Word。
  · 深度调研（1.7 新增）：写下研究问题，AI 自动检索、逐篇判断相关度并抽取成表格（可导出 Excel 能打开的 CSV）；
    “调研报告”模式会按发现的缺口多轮检索，最后写出每句都带出处的调研要点。只依据题名和摘要。
  · 写论文（1.7 新增）：给新进组同学的论文向导——选论文类型（课程论文、大创结题、挑战杯、数学建模国赛、毕业论文、
    中文期刊、Nature、Nature Communications），看每一节写什么和排版要求，下载排好版的 Word / LaTeX 模板，
    让 AI 带着列提纲（不代写）；写完上传 Word 或 LaTeX 做格式与投稿规范检查。
  · 学科技能库（1.7 新增）：本机智能体内置写作、投稿、文献、生物医药化学、数据与图表、诚信、实验等 19 个技能，
    也可以从 GitHub 一键导入别人写好的 SKILL.md。
  · 流程：选模板（课题组科研 / 大创·挑战杯 / 数学建模等限时赛 / 通用），每个阶段有目标、做法、交付清单，学生提交、老师审核，全程留痕。
  · 资料库：上传 PDF、Markdown、TXT（扫描件可用 OCR 识别，1.6 新增）；问答只依据选定资料回答，每条结论都能点开原文，资料里没有的会直接说明。
  · 引用核验：粘贴论文全文，检查参考文献能否在公开数据库找到，并对照上传的原文逐句核对引用。
  · 文献检索（1.1 新增）：AI 帮你把研究问题拆成中英文检索词；检索公开数据库 OpenAlex；
    可免费下载的论文一键下载全文收入资料库，其他收入题录+摘要；自动生成 GB/T 7714 参考文献格式；
    每次检索的检索词、条件、结果和收入的文献自动记录。知网/万方的题录可导出后导入。
  · AI 读文献（1.4 新增）：资料列表点“AI 速读”，得到一句话概括、研究问题、方法、主要发现、局限、关键术语和
    “读前需要的知识”；遇到看不懂的概念点一下就讲解。“文中怎么说”都附原文出处，“通俗解释”标明是 AI 通用知识。
    同一份资料的速读和讲解全组共用，不重复花钱。
  · 傻瓜接入与按难度分配（1.4 新增）：“一步步接入”向导，选服务商 → 粘贴密钥 → 自动识别可用模型并推荐
    “日常模型 + 难题模型”→ 自动自检和启用。简单任务用便宜的日常模型，难题自动交给难题模型；
    日常模型回答不合格时自动升级重试。“用量与花费”页面按任务、模型、成员统计 tokens、成功率、耗时和花费，并给出优化建议。
    老师可以只配一个团队模型，并给每人设置每月额度，学生什么都不用配。
  · LaTeX 导出 PDF（1.5 新增）：识别出的公式、表格、段落和手绘生成的图，一键编译成 PDF，页面里直接预览和下载；
    编译出错时指出第几行、什么原因、怎么改。需要电脑上装有 TeX Live 或 MiKTeX（见“十”）。
  · 手绘转图（1.5 新增）：用鼠标、手指或手写笔随手画草图（也可以拍纸上的草图），AI 理解你想画什么
    （流程图、函数图像、几何图、实验装置、数据图、电路、网络结构），生成规范的 TikZ 代码和预览，
    一句话就能调整，可导出 PDF 或交给智能体插进论文。
  · 本机智能体（1.5 升级，原“本机文件助手”）：像一个会用电脑的助理，自己规划步骤完成任务——
    查找、阅读、修改文件；整理文件夹（新建、移动、复制、删除）；运行命令和 Python 脚本（处理数据、画图）；
    编译 LaTeX 并根据报错修改；读网页；检索文献并加入资料库；记住你的习惯；按“技能”做事；定时自动执行任务。
    改文件、移动、删除都要你点“应用”，运行命令前会弹出确认，所有操作可撤销、有记录。
  · AI 助手（1.3 新增）：
    - 图片转 LaTeX：公式、表格、论文截图、手写笔记拍照/截图，直接得到 LaTeX，带公式预览和语法检查；手机也能用。
    - 本机文件助手：在你授权的文件夹里查找、阅读、修改文件（尤其是 .tex 论文），可以“按图片上的批注改论文”。
      每处修改都要你确认才写入，写入前自动备份，可以撤销。只能在运行工作台的电脑上使用。
  · Zotero 直连（1.2 新增）：浏览自己的 Zotero 文库（含分类、课题组群组文库），带 PDF 一键导入资料库；
    检索到的新文献一键存回 Zotero。
  · 每人用自己的 AI 模型（1.1 新增）：设置 → 我的 AI 模型，添加自己的服务商和 Key，通过“兼容性自检”后启用。
  · 经验库：项目结束后归档复盘，下一届一键复制流程。

二、第一次使用（老师）
  1. 双击桌面“CanDo 可为”图标，创建管理员账号。
  2. 设置 → 成员：为学生创建账号（用户名 + 初始密码），把账号告诉学生。
  3. 设置 → 团队默认 AI 模型：选择服务商，填入 API Key，点“测试连接”和“兼容性自检”。
     （不配置也能使用流程和资料库，但问答和引用核验只能列出原文片段。）
     成员也可以在“设置 → 我的 AI 模型”里用自己的 Key，互不影响。
  4. 首页 → 新建项目：选择模板，勾选成员。
  5. 设置 → 手机与同学访问：勾选开启，学生用手机扫码登录。

三、手机怎么装
  先在电脑上打开“设置 → 手机与同学访问”，勾选开启，页面上会出现两个二维码。手机和电脑连同一个 Wi-Fi。
  · 安卓手机：扫二维码①，下载并安装“CanDo”App（首次需允许“安装未知应用”；
    App 未上架应用商店，提示风险时选“继续安装”）。打开 App，输入电脑上显示的访问地址并连接，然后登录。
    也可以把电脑上的“CanDo_安卓App.apk”通过数据线或 QQ 发给同学安装。
  · 苹果手机（1.8 起）：用相机扫二维码①，在 Safari 里按页面提示点“打开工作台”并登录，再点底部“分享”
    → “添加到主屏幕”。桌面上会出现“CanDo”图标，从图标打开是全屏的，用起来和 App 一样，
    不需要 App Store、不需要苹果账号。用 Safari 打开工作台时，页面底部也会提示怎么添加。
    （微信里扫码打开的，请点右上角“…” → “在默认浏览器中打开”，微信里没有“添加到主屏幕”。）
  · 苹果原生 App（可选）：源码包里的 ios 文件夹是原生 iOS App 工程，需要 Mac + Xcode 编译，
    用免费 Apple ID 装到自己手机上（7 天后需重新安装），或用苹果开发者账号（688 元/年）通过 TestFlight 发给同学。
    步骤见 ios/README.md。
  电脑需要开着，并且工作台在运行。
  打不开时：确认同一个 Wi-Fi；部分校园网禁止设备互访，可让电脑连接手机热点。

四、需要知道的
  · 工作台在默认浏览器（如 Chrome）中打开，地址是 http://127.0.0.1:18765 ，可以收藏到书签。
  · 关闭浏览器标签后工作台仍在后台运行（方便手机访问）。完全退出：设置 → 关于 → 退出工作台程序。
  · 数据只保存在这台电脑：C:\Users\你的用户名\AppData\Local\KeyanWorkbench\data
    管理员可在“后台”页面查看全部项目进度、全局动态和数据占用，一键打开数据文件夹或下载完整备份。
    换电脑：在新电脑安装后，把备份里的 data 文件夹复制到同一位置。
  · 使用 AI 模型时，只有检索到的少量相关片段会发给你设置的模型服务商；不会发送全文。
  · 引用核验联网核对时，只把参考文献题名发送给公开文献数据库 OpenAlex。
  · 引用核验结果只有“有原文对应 / 部分对应 / 待核查 / 未核验”，是帮助审阅的辅助信息，不是对作者的判定。
  · 扫描件 / 图片 PDF（1.6 新增 OCR）：上传后会提示“要现在用 AI 识别文字吗”，也可以在资料列表点“OCR 识别”。
    需要一个能看图片的模型（设置 → 我的 AI 模型，勾选“能看图片”并通过自检）。只识别没有文字的页，每页调用一次识图模型，
    页数多时有一定费用（“用量与花费”里的“扫描件识别”）。可以中途停止，已识别的页会保留，之后再点“OCR 识别”补做剩下的页。
    识别出的文字在引用处标注“OCR 识别”，可能有错字，请对照原文件。
  · 暂不支持：Word 文件（请另存为 PDF）、音视频。

五、AI 模型怎么选（1.1）
  · 使用顺序：项目指定的模型 → 自己启用的模型 → 团队默认模型。每次回答下方会显示“由哪个模型生成”。
  · 自检结果分三种：“自检通过”；“基本通过”（能连通、能按原文带引用回答，但有提醒项没通过，例如免费小模型
    复述了文档里的指令——可以启用，系统使用时会校验每条引用、丢弃无效引用）；“自检未通过”（连不上或不能按原文回答，不能启用）。
  · 新模型要先通过“兼容性自检”（5 项：连通、按原文回答、资料不足如实说明、不听从文档里的指令、引用核验不误判），
    通过后才能启用。自检只说明模型守规则，不代表回答质量。
  · 组员之间分享配置：点“导出配置卡”得到一个 JSON 文件（不含 Key），对方“导入配置卡”后填自己的 Key 即可。
  · 每个人的 Key 加密保存在运行工作台的电脑上，只用于本人请求，管理员也看不到。建议用单独的、设了额度上限的 Key。
  · 项目“管理”页可以给整个项目指定一个模型；指定自己的模型意味着项目里所有人的调用费用记在你的 Key 上。

六、文献检索怎么用（1.1）
  · 项目里点“文献检索”（个人检索在“我的资料 → 文献检索”）。
  · 出现“检索太频繁”：OpenAlex 从 2026 年起按每日额度限制，不填密钥时每天只能检索约 100 次，而且同一个校园网的人共用。
    解决：到 openalex.org 注册（30 秒），在 openalex.org/settings/api 复制免费密钥，填到“设置 → 文献数据库”
    （老师填“团队密钥”后全组都能用），每天约 1000 次。额度用完时工作台会自动改用 Crossref 检索，相同检索 12 小时内直接用缓存。
  · 运行工作台的电脑需要能上网。OpenAlex 英文文献较全，中文期刊覆盖有限；中文文献请点“去知网检索”，
    在知网勾选文献 → 导出 → 选 RIS 或 EndNote 格式（UTF-8），再点“导入题录文件”。
  · “收入资料库（下载全文）”只对开放获取论文有效；需要登录的出版社网站请手动下载 PDF 后在“资料”页上传。
  · 只收入题录和摘要的文献，问答只能依据摘要；要逐句核对引用，请上传全文 PDF。
  · 参考文献格式由数据库信息自动生成，卷期页码等可能不全，投稿前请核对。

七、Zotero 怎么连（1.2）
  · 在运行工作台的电脑上（本机 Zotero，不用填任何东西）：
    需要 Zotero 7 或更新版本。打开 Zotero → 编辑 → 设置 → 高级，勾选“允许此计算机上的其他应用程序与 Zotero 通信”，
    并保持 Zotero 开着。然后在项目“文献检索 → 从 Zotero 导入”里选择分类、勾选文献、导入。
  · 在手机或其他电脑上（Zotero 云端，每人设置一次）：
    1. 用电脑浏览器打开 zotero.org/settings/keys/new 并登录（与 Zotero 软件同步用的账号相同）；
    2. 勾选 Allow library access；想把检索结果存回 Zotero，再勾选 Allow write access；有课题组群组文库的，Groups 选 Read Only；
    3. 保存后复制密钥，粘贴到工作台“设置 → 我的 Zotero”，点“连接”。
    要从云端下载 PDF，需要在 Zotero 软件“设置 → 同步”中开启“同步附件文件”。“链接到文件”的附件只在原电脑上，云端下载不到。
  · 有 PDF 附件的导入全文（可以问答、逐句核对引用）；没有的导入题录和摘要。已在资料库里的会标出“已在资料库”，不会重复导入。
  · 每次导入的文库、分类和导入的文献会记入“检索记录”。
  · 在线检索结果上的“存到 Zotero”：本机会存到 Zotero 中当前选中的分类；云端会存到你的文库，同步后在 Zotero 里可见。都会带“CanDo 可为”标签。
  · 你的 Zotero 密钥加密保存，只用于你自己的请求，管理员也看不到。

八、AI 助手怎么用（1.3）
  · 图片转 LaTeX（左侧“AI 助手”）：
    需要一个“能看图片”的模型：设置 → 我的 AI 模型 → 添加，服务商选“通义千问 VL”“智谱 GLM-4V”“豆包视觉”或 Claude，
    勾选“这个模型能看图片”，通过兼容性自检（会多一项“看图识别公式”）。DeepSeek 等纯文字模型不能看图。
    选择或粘贴图片（截图后直接 Ctrl+V）→ 选类型（公式 / 表格 / 段落 / 手写 / 批注）→ 识别 → 复制。
    识别结果可能有误，请对照原图核对；预览用的是网页公式渲染，最终以 LaTeX 编译为准。
  · 本机文件助手（只能在运行工作台的电脑上用）：
    1. 在右侧“授权文件夹”添加论文所在的文件夹（例如 D:\论文\毕业论文），选“可修改”或“只读”。
       不能授权整个磁盘、系统文件夹；工作台自己的数据文件夹始终禁止访问。
    2. 用中文说要做什么，例如“检查 chapters 里所有 tex 文件的括号和环境”“把 main.tex 的表 2 改成三线表”，
       或者附上打印稿批注的照片，说“按图片1 的批注修改 main.tex”。
    3. 助手提出的修改显示在“待确认的修改”里（红色删除、绿色新增），并自动做 LaTeX 检查。点“应用”才写入；
       写入前备份原文件，点“撤销”可恢复。如果你在这期间自己改过文件，助手不会覆盖。
    4. 助手只能写文本类文件（.tex .bib .md .txt .py 等），不能写 .exe/.bat 等可执行文件，不读取密钥类文件（如 .env）。
    5. “操作记录”里能看到助手读了哪些文件、改了什么。
  · 建议：编辑器（TeXstudio、VS Code 等）开着同一个文件时，应用修改后请在编辑器里重新载入。

九、不会接 API 怎么办（1.4）
  · 最省事：老师在“设置 → 团队默认 AI 模型”点“一步步接入”配一次，学生什么都不用做。
    可以填“每人每月额度”（元），超出后该同学只能用自己接入的模型，避免有人用太多。
  · 自己接入：设置 → 我的 AI 模型 → “一步步接入（推荐）”：
    1. 选服务商。想省钱选智谱 GLM（有免费模型）；想效果好又便宜选 DeepSeek 或通义千问；
    2. 按页面上的链接注册、创建 API Key，复制粘贴进来；
    3. 系统自动验证密钥、列出可用模型、推荐日常模型和难题模型、填好参考价，点“保存并自检”即可。
  · 按难度分配：拆检索词、文献速读、概念讲解用日常模型；引用核验、资料对比、本机文件助手、带“为什么/比较/推导”等的
    问题用难题模型。问答时也可以手动选“快速”或“深度”。回答下方会写明用了哪个模型、为什么。
  · 花费是按“tokens × 你填的价格”估算的，参考价会随服务商调整，以官网和账单为准。

十、LaTeX 导出 PDF 与手绘转图（1.5）
  · 导出 PDF 要用运行工作台那台电脑上的 LaTeX，只需装一次，二选一：
    - TeX Live（推荐，功能全）：到清华镜像 https://mirrors.tuna.tsinghua.edu.cn/CTAN/systems/texlive/Images/
      下载 texlive.iso，双击打开，运行 install-tl-windows.bat，一路默认，约 30–60 分钟、占 8 GB 左右。
    - MiKTeX（体积小）：https://miktex.org/download 下载安装；缺少的宏包在编译时自动下载（第一次会慢一些）。
    装好后在页面上点“重新检测”；如果还检测不到，重启一下工作台。
  · 图片转 LaTeX：识别后点“导出 PDF”。公式片段、表格、段落会自动补上导言区（含中文用 ctex + XeLaTeX）。
  · 手绘转图（AI 助手 → 手绘转图）：
    1. 在画板上画（笔、橡皮、颜色、粗细、撤销），或点“拍照 / 上传草图”，也可以直接粘贴截图；
    2. 选图的类型（不确定就选“自动判断”），可以写一句补充说明，例如“曲线是 y=e^{-x}”“三个框从左到右”；
    3. 点“生成图”，得到 AI 理解的意图、预览和 TikZ 代码；不满意就在“一句话调整”里说，例如“箭头改成虚线”；
    4. 复制代码、导出 PDF，或“交给智能体放进论文”（它会加 figure 环境、图题和缺少的宏包，并编译确认）。
    需要能看图片的模型。预览是示意，以 PDF 为准。
  · 编译出错时：页面会列出“第几行 + 原因 + 怎么改”，行号对应“查看实际编译的完整文档”里的行号。

十一、本机智能体（1.5）
  只能在运行工作台的电脑上使用。右侧有五个标签：
  · 待确认：智能体提出的修改（红删绿增）、新建/移动/复制/删除文件、编译生成的 PDF。点“应用”才执行，
    可以“全部应用”，执行后能“撤销”。删除不会真的删掉，而是移到工作台回收区，撤销即可放回。
  · 文件夹与权限：
    - 授权文件夹：智能体只能看到和操作这里的文件夹，命令也只能在这些文件夹里运行。
    - 运行命令：默认“每次先问我”。弹出确认时可以“允许一次”“始终允许 python”（以后同一程序不再问）或“拒绝”，
      10 分钟不处理自动拒绝。删除、改注册表、下载执行、关机等危险命令标红，每次都要确认，不能设为始终允许。
    - 打开文件和网址：每次问 / 直接打开 / 不允许。读取网页：允许 / 不允许。
  · 记忆：智能体每次对话都会先读，适合写“论文在 D:\论文，用 XeLaTeX 编译”“参考文献用 GB/T 7714”这类习惯。
    对话里说“记住……”它也会自己记下。不要写密码和密钥（智能体也会拒绝记住像密钥的内容）。
  · 技能：写好的做事步骤。内置“编译并修复 LaTeX”“整理文件夹”“文献追踪”“论文格式检查”“用 Python 处理数据”，
    可以新建、编辑，也可以导入 SKILL.md 文件。说“用‘整理文件夹’技能处理 D:\下载”即可调用。
  · 定时任务：例如“每周一 8:30 追踪新文献并加入资料库”“每天晚上检查论文能否编译”。
    工作台开着时才执行，关机错过的会在下次打开后补做一次。无人值守时不会运行需要确认的命令，
    改文件也只放进“待确认”，等你回来处理。“立即执行”可以先试一次。
  · 运行 Python：智能体用电脑上已安装的 Python；没装的话可从 python.org 安装（勾选“Add to PATH”）。
  · 所有操作都记录在“操作记录”里。

十二、论文库、深度调研和写论文（1.7）
  · 论文库：左侧“论文库”是个人的；项目里的“论文库”标签是项目共用的。三块内容：
    - 库中论文：上传 PDF/Markdown/TXT；扫描件点“OCR 识别”；点“AI 速读”快速读懂；点“提取的文字”看系统读到了什么。
    - 检索添加：在线检索（OpenAlex / Crossref）、从 Zotero 导入、导入知网等导出的题录。
    - 深度调研：见下。
  · 深度调研：
    1. 写下研究问题，选“文献筛选”（快，出表格）或“调研报告”（多轮检索，写要点）。
    2. 可以改“抽取的列”（默认：研究对象、方法、样本/数据、主要结论），以及每轮最多多少篇、几轮、起始年份，或自己指定英文检索式。
    3. 结果表按相关度排序（3 直接相关、2 高度相关、1 有点关系、0 无关），每篇都写了理由；可以导出 CSV、复制 GB/T 7714 引用、
       把勾选的文献收入论文库。调研报告中每条结论后面的 P 编号可以点，跳到对应文献。
    4. AI 只看了题名和摘要，“摘要未提及”表示要看全文；重要结论请打开原文核对。每轮检索会记录“新增了几篇相关文献”，
       没有新增或没有新的检索方向时自动停止。
  · 写论文 → 新手向导：
    1. 选论文类型，看每一节写什么、篇幅、常见问题，以及排版要求（依据国赛论文格式规范 2026 修订稿、GB/T 7713.1—2006、
       GB/T 7714—2015、Nature 和 Nature Communications 投稿指南；学校和期刊的细则以官方通知为准）。
    2. 下载 Word 或 LaTeX 模板：页面、字体、标题样式、图题表题位置、三线表、参考文献格式都已设好，灰色文字是写作提示。
    3. “让 AI 带你列提纲”：给每一节列出要回答的问题、小标题和要准备的材料，不替你写正文。
  · 写论文 → 格式与投稿规范检查：上传 .docx 或 .tex（也可以粘贴文字），选论文类型。会检查：
    必需的章节、题名长度、摘要字数、关键词个数、章节编号、图题表题的位置和编号、图表是否在正文中提到、
    参考文献与正文引用是否一一对应、顺序编码、GB/T 7714 条目格式（类型标识、年份、作者超过 3 位写“等”、半角标点）、
    中文里混用英文标点、页边距和纸张；数学建模国赛还检查身份信息（学校、队员、赛区）和附录中的源程序；
    Nature 系列检查字数、参考文献条数、图表数量、图注长度和必需的声明。
    勾选“AI 看内容”时，AI 会看摘要、引言、结论和章节结构，给出内容上的修改建议。
    旧版 .doc 请先在 Word 里另存为 .docx；PDF 无法可靠识别格式。
  · 学科技能库（AI 助手 → 本机智能体 → 技能）：按类别列出内置技能，每个都注明思路来源和许可证；
    可以粘贴 GitHub 上技能文件夹的网址一键导入（只导入步骤说明，不下载脚本）。标了 NC 的许可证禁止商业用途。

十三、全组共享和 AI 起草（1.9）
  · 共享论文：论文库 → 我的论文，在论文后面点“共享到全组”（再点一次取消）。共享前请确认没有版权或保密限制。
    其他同学在“论文库 → 全组共享”里看到这篇论文，可以看原文、AI 速读，在“问答”和“AI 起草”里选用；不能修改或删除。
    管理员可以取消任何共享。项目里的论文库本来就对项目成员可见，不需要共享。
  · AI 起草的步骤：
    1. 选论文类型、要写的章节（例如引言、摘要、讨论）和语言；
    2. 用自己的话写下这一节想表达的内容（必填：研究问题、做法、主要发现、观点，每行一条），以及你的结果和数据（可选）；
    3. 选参考的论文（我的论文 + 全组共享，或某个项目的论文库），点“生成论证骨架”；
    4. 骨架列出每个论点、它在论证中的作用（背景、缺口、问题、做法、发现、支撑、边界、意义）和依据：
       N 是你提供的内容，F 是论文原文（点一下可以看原文）；没有依据的论点标“需要补充”。可以修改文字和作用、删除或添加论点；
    5. 点“按骨架起草”，得到正文。黄色 = 没有依据的陈述，橙色 = 需要你补充的内容；下面有字数、依据、夸大用词等检查结果；
    6. 复制正文或下载 Word：论文原文的引用自动换成 [1] [2]… 并生成参考文献（上传的论文缺刊名卷期等信息，会标［待补充］）。
  · 写作规则：摘要按“问题 → 缺口 → 做法 → 主要发现 → 关键支撑或边界 → 意义”（Nature 类按官方 summary paragraph 的结构），
    引言按“漏斗”逐步收窄到确切的研究问题，结果逐步升级论证，讨论按“核心发现 → 综合 → 与已有研究比较 → 局限 → 意义”，
    中文摘要写全目的、方法、结果、结论。参考了 Nature 官方写作指南和 nature-skills（Apache-2.0）等开源写作规范。
  · 请注意：研究发现和数据只能来自你自己提供的内容，AI 不会也不应该替你编造结果或文献；起草稿需要你逐句核对、用自己的话修改，
    并按学校或期刊要求声明使用了 AI。

十四、后台任务（1.10）
  · 点了“生成论证骨架”“按骨架起草”“生成提纲”“开始检查”“提交问题”“AI 速读”等按钮后，任务在老师电脑上的工作台里运行，
    页面可以关掉、刷新或去做别的事，也可以接着再发起一份起草。
  · 右上角出现“后台任务”按钮：绿点表示都已完成，蓝点闪烁表示有任务在进行；点开可以看每个任务的状态，
    完成的点“查看结果”跳到对应页面并显示结果，出错的会写明原因。AI 起草的结果也会出现在“我的草稿”里，问答结果在问答历史里。
  · 每人最多 3 个任务同时运行，多出来的自动排队；全组合计最多 8 个同时运行。
  · 任务结果保存在工作台内存里（最近 40 个、24 小时），工作台程序关闭或重启后清空，未完成的任务会中断（已保存的草稿、问答不受影响）。

十五、常见问题
  · 双击后提示“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”（程序暂未做数字签名）。
  · 杀毒软件拦截：请将安装目录加入信任。
  · 忘记管理员用户名：在运行工作台的电脑上打开登录页，页面上会显示本机管理员用户名。
  · 忘记管理员密码：开始菜单 → CanDo 可为 → 忘记管理员密码。会弹窗显示用户名和临时密码，
    用临时密码登录后在“设置”中改成自己的密码，所有数据不受影响。
    （免安装版：在程序文件夹中打开终端，运行 .\CanDo.exe -reset-admin）
  · 其他成员忘记密码：管理员在“设置 → 成员”中点“重置密码”。
  · 修改自己的用户名或显示姓名：设置 → 我的账号。修改团队名称：设置 → 团队名称（管理员）。
  · 卸载：开始菜单 → CanDo 可为 → 卸载。卸载时可选择是否保留数据。
